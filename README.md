# Anime Versus Game V2.9 – GitHub Pages Edition

Diese Ausgabe ist **direkt deploybar** und benötigt keinen Build-Schritt.

## GitHub Pages
1. `index.html` und diese `README.md` in die oberste Ebene des Repositories hochladen.
2. GitHub → Settings → Pages.
3. Deploy from a branch → `main` → `/ (root)` → Save.
4. Danach die GitHub-Pages-URL öffnen.

## Enthalten
- 7v7 Draft, Ban, Joker, Mystery, Double, Trade, Captain und Lineup
- V2.9 Hybrid-Finale: 4 Duellsiege, verdeckte Karten, Energie, Finisher, kurze Erzählung
- optionaler Cinematic Auto-Fight
- Browser-TTS und optionale Puter-KI-Langfassung
- Ergebnisbild und Ergebnislink
- GitHub-taugliches Online-System mit Multi-Transport/PeerJS-Fallback
